# Part 1 — English

# React & Next.js Study Plan

**Study Period:** 6 Weeks  
**Study Approach:** Official documentation, self-study, hands-on practice, and daily progress reporting

---

## 1. Study Objectives

- Build a solid understanding of React fundamentals and component-based development.
- Develop practical skills through coding exercises and small projects.
- Understand React state, events, hooks, forms, component composition, and common patterns.
- After gaining sufficient React understanding, move to Next.js and study its modern application architecture.
- Apply the knowledge to a practical project that demonstrates React and Next.js development skills.

---

## 2. Documentation to Study First

The first stage will focus on the official React documentation.

**React Official Documentation:**  
https://react.dev/learn

Study order:

1. Quick Start
2. Describing the UI
3. Adding Interactivity
4. Managing State
5. Escape Hatches

After understanding the React fundamentals, continue with the official Next.js documentation.

**Next.js Official Documentation:**  
https://nextjs.org/docs

---

## 3. Six-Week Roadmap

| Week | Main Focus | Key Topics | Expected Result |
|---|---|---|---|
| **Week 1** | React Fundamentals | JSX, Components, Props, Conditional Rendering, Lists, Events | Understand how React builds and renders UI. |
| **Week 2** | React State & Interaction | useState, Forms, Events, Lifting State, Sharing State | Build interactive React applications. |
| **Week 3** | Advanced React Basics | useEffect, useRef, Context, useReducer, Custom Hooks, Composition | Apply common React patterns correctly. |
| **Week 4** | Next.js Fundamentals | App Router, Pages, Layouts, Routing, Server/Client Components | Understand the Next.js application structure. |
| **Week 5** | Next.js Application Development | Data Fetching, Route Handlers, Server Actions, Forms, Authentication Concepts | Build a practical Next.js application. |
| **Week 6** | Advanced & Production | Caching, Rendering, Performance, SEO, Security, Deployment, Docker/CI/CD | Understand production considerations for Next.js. |

---

## 4. React Study Topics

- JSX and JavaScript expressions
- Functional Components
- Props and Component Composition
- Conditional Rendering
- Rendering Lists and Keys
- Event Handling
- State with `useState`
- Forms and Controlled Inputs
- Sharing and Lifting State
- Effects with `useEffect`
- Refs with `useRef`
- Context API
- `useReducer`
- Custom Hooks
- Performance basics and React DevTools

---

## 5. Next.js Study Topics

- Next.js App Router and project structure
- Pages and nested layouts
- Dynamic routes and navigation
- Server Components and Client Components
- Data fetching
- Loading and error UI
- Route Handlers
- Server Actions
- Forms and validation
- Authentication and session concepts
- Cookies and environment variables
- Caching and revalidation
- Static and dynamic rendering
- Metadata and SEO
- Image and font optimization
- Security and production considerations
- Deployment, Docker, and CI/CD

---

## 6. Hands-on Practice Projects

### Project 1 — Todo Application

Practice components, props, state, events, forms, and list rendering.

### Project 2 — User Management Dashboard

Practice CRUD UI, search, filtering, pagination, reusable components, and form validation.

### Project 3 — Full-Stack Expense Management System

Build a practical application using Next.js with a backend API and PostgreSQL. The project can include authentication, dashboard, expense CRUD, categories, search/filtering, pagination, and charts.

---

## 7. Daily Study & Reporting Method

Each study day will have a short report based on the actual topics studied and practice completed.

The daily report should contain:

| Section | What to Record |
|---|---|
| **Date** | Study date |
| **Documentation Studied** | Documentation pages, chapters, or topics completed |
| **What I Learned** | Important concepts understood that day |
| **Practice** | Coding exercises or project work completed |
| **Problems / Questions** | Difficult or unclear topics |
| **Next Plan** | Topics planned for the next study session |

**Study principle:** Daily reports should be based on personal study notes, actual coding practice, and personal understanding rather than AI-generated study content.

---

## 8. Expected Outcomes

After completing the roadmap, the expected outcomes are:

- Explain core React concepts and common React development patterns.
- Build reusable and maintainable React components.
- Develop interactive applications using state, hooks, forms, and component composition.
- Understand the difference between Server Components and Client Components in Next.js.
- Build a Next.js application using routing, data fetching, forms, and API integration.
- Understand basic performance, security, SEO, caching, and deployment considerations.
- Complete a practical project demonstrating React and Next.js skills.

---

## 9. Learning Sequence

The learning sequence will follow a React-first approach:

**React Fundamentals**  
↓  
**React State & Hooks**  
↓  
**React Practice Project**  
↓  
**Next.js Fundamentals**  
↓  
**Next.js Application Development**  
↓  
**Advanced Next.js**  
↓  
**Production Project**  

---

## 10. Study Principle

React fundamentals will be studied first because Next.js is built on React. The study will focus on understanding concepts through official documentation and hands-on coding rather than only reading theory. Each topic will be practiced before moving to the next major stage.

## 7. 일일 학습 및 보고 방법

매 학습일마다 실제로 학습한 내용과 실습 결과를 바탕으로 간단한 일일 학습 보고서를 작성합니다.

일일 보고서에는 다음 내용을 포함합니다.

| 항목 | 작성 내용 |
|---|---|
| **날짜 (Date)** | 학습 날짜 |
| **학습 문서 (Documentation Studied)** | 학습한 공식 문서, 챕터 또는 주제 |
| **학습 내용 (What I Learned)** | 해당 날짜에 이해한 주요 개념 |
| **실습 내용 (Practice)** | 완료한 코딩 실습 또는 프로젝트 작업 |
| **문제 및 질문 (Problems / Questions)** | 이해하기 어려웠거나 추가 학습이 필요한 내용 |
| **다음 학습 계획 (Next Plan)** | 다음 학습에서 진행할 주제 |

**학습 원칙:** 일일 학습 보고서는 실제로 학습한 내용, 직접 작성한 코드 및 개인적인 이해를 바탕으로 작성하며, AI가 생성한 학습 내용을 그대로 사용하지 않습니다.
